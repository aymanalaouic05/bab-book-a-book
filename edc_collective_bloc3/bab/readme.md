# Book A Book - BAB

## Outils de suivi utilisés
GitHub Issues

## Points forts
- Création et suivi des anomalies et nouvelles fonctionnalités facilement
- Assignation des issues aux membres de l'équipe
- Lien direct entre les issues et les branches/commits via les références (#1, #2...)
- Historique complet des corrections et discussions sur chaque issue
- Intégration native avec Git et le workflow GitFlow

## Limites
- Pas de gestion de priorité avancée sans plugins supplémentaires
- Pas de tableau Kanban natif (contrairement à Jira)
- Difficile à utiliser pour de très grands projets avec beaucoup d'issues
- Pas de gestion du temps ou estimation de charge intégrée
